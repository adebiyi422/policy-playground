Build the Policy Playground

You build two AI assistants for a fictional health insurer, Oak Health Insurance. They use the same model and the same tools. Only one of them follows policies. You send both the same message, watch what each one does, and count the rules the assistant without policies breaks. At the end, you can put it online as your own Hugging Face Space.

This is a rebuild of IBM Research's CUGA Policy Playground Space, cut down to the parts you need to understand it. No programming background is needed: every step gives you the exact command, the file to use, and the result you should see. Each "Expected" box was copied from a real run.

What a policy is

A rule CUGA enforces around the model, written in a small text file. The model can't talk its way past it. You'll use four kinds:

  • Tool approval: pause and ask the member before a tool runs
  • Intent guard: refuse a kind of request before any tool runs
  • Playbook: step-by-step instructions for a kind of task
  • Output formatter: change the final answer, such as adding a disclaimer

Install Docker and git

Docker runs the project in a small Linux box, called a container, so you don't have to install Python packages on your own computer. CUGA needs PyTorch 2.13 or later, which has no build for Intel Macs, so the container is required there. It is also the path this tutorial was tested on.

On Windows: install WSL first, with wsl --install in PowerShell, then restart. Run every command in this tutorial from the Ubuntu terminal that WSL adds. cuga-docker.sh is a bash script, so it doesn't run in PowerShell. In Docker Desktop, turn on Settings → Resources → WSL integration for Ubuntu.

The insurer as tools

Read a policy file

Each file has two parts. Between the --- lines are the settings: the kind of policy, and when it applies. Below them is the text: the refusal message, the instructions, or the note to add.

Let the code handle the Bob key

Create playground/model_setup.py. When the address is Bob's, it picks Bob's preset and adds Apikey to the key, so neither can be forgotten:

"""Model settings the code can work out for itself. Import this before anything that imports cuga."""

import os

if "bob.ibm.com" in os.environ.get("OPENAI_BASE_URL", ""):
    os.environ["AGENT_SETTING_CONFIG"] = "settings.bob.toml"  # Bob's preset sends the headers Bob requires
    key = os.environ.get("OPENAI_API_KEY", "").strip().strip('"')
    if key and not key.startswith("Apikey "):

Count broken rules from what the policies did

Now each button lists its own rules, and a typed message only gets the approval and denied-claim rules. Instead, let the right side's policies decide: if its disclaimer fired, the left side needed one too, and if its guard refused, the left side shouldn't have answered. Add this to the end of playground/scenarios.py:

# Step 6.3: which rules to check, from what the policies did on the right side.
DISCLAIMERS = {"Medical information disclaimer": "medical_disclaimer", "Plan advice disclaimer": "plan_disclaimer"}


def rules_from_policies(right: dict) -> list:
    """Approval and denied-claim rules always apply. A guard or disclaimer rule applies when that policy fired."""
    fired = [entry.rpartition(": ") for entry in right["policies"]]
    if any(outcome == "blocked" for _, _, outcome in fired):
        return ["approval", "denied_claim", "guard"]  # a refusal needs no disclaimer
    rules = ["approval", "denied_claim"]
    for name, _, outcome in fired:
        if outcome == "applied" and name in DISCLAIMERS:
            rules.append(DISCLAIMERS[name])
    return rules

In playground/web.py, import it with from scenarios import SCENARIOS, check_rules, rules_from_policies. Then, in api_ask, replace the five lines from the first reset_data() to right = _side(…) with:

        reset_data()
        left = {**await ask(state["agents"]["without"], body.message), "approvals": 0, "bills": bills()}
        reset_data()
        right_raw = await ask(state["agents"]["with"], body.message)
        right = {**right_raw, "approvals": 1 if right_raw["paused"] else 0, "bills": bills()}
        rules = rules_from_policies(right)  # step 6.3: what the policies did decides what to check
        for out in (left, right):
            out["broken"] = [] if out["paused"] else check_rules({"rules": rules}, out)

6.415 min

Say what changed in one line

Add this function to playground/web.py, above @app.get("/"):

def difference(left: dict, right: dict) -> str:
    """Step 6.4: one sentence that says what the policies changed."""
    if right["paused"]:
        return "Right is waiting for your approval. " + ("Left already ran it." if left["tools"] else "Left didn't ask.")
    if any(p.endswith(": blocked") for p in right["policies"]):
        return "Right refused with a guard. " + ("Left answered it using tools." if left["tools"] else "Left refused on its own.")
    n = len(left["broken"])
    if n:
        return f"Left broke {n} rule{'s' if n != 1 else ''}. Right broke {len(right['broken'])}."
    return "No policy changed the outcome for this message."

Make api_ask return it, by changing its last line to:

        return {"without": left, "with": right, "difference": difference(left, right)}

In playground/index.html, add a place for the line just above <div class="cols">, and its style in the <style> block:

<p class="difference" id="diff"></p>
.difference { font-weight:600; margin:0 0 12px; min-height:1.5em; }

In send(), clear it with $("diff").textContent = ""; before the request, and fill it after the two render calls with $("diff").textContent = res.difference || "";. Clear it in decide() too, since an approval changes the answer.

def _resolve(spec: dict, schema: dict) -> dict:
    while "$ref" in schema:
        schema = spec["components"]["schemas"][schema["$ref"].split("/")[-1]]
    return schema


def _py_type(spec: dict, schema: dict):
    schema = _resolve(spec, schema)
    for option in schema.get("anyOf", []):
        if option.get("type") != "null":
            return _py_type(spec, option)
    if schema.get("type") == "array":
        return List[_py_type(spec, schema.get("items", {}))]
    return _TYPES.get(schema.get("type"), Any)


def make_tools() -> List[StructuredTool]:
    """One tool per Oak Health endpoint, generated from the OpenAPI spec."""
    spec = oak_main.app.openapi()
    client = httpx.AsyncClient(transport=httpx.ASGITransport(app=oak_main.app), base_url="http://oak.local")
    tools = []
    for path, methods in spec["paths"].items():
        for method, op in methods.items():
            fields: Dict[str, Any] = {}
            where: Dict[str, str] = {}
            for p in op.get("parameters", []):
                py = _py_type(spec, p.get("schema", {}))
                if p.get("required"):
                    fields[p["name"]] = (py, Field(..., description=p.get("description") or ""))
                else:
                    fields[p["name"]] = (Optional[py], Field(p.get("schema", {}).get("default"), description=p.get("description") or ""))
                where[p["name"]] = p["in"]
            body = op.get("requestBody", {}).get("content", {}).get("application/json", {}).get("schema")
            if body:
                body = _resolve(spec, body)
                required = set(body.get("required", []))
                for name, prop in body.get("properties", {}).items():
                    py = _py_type(spec, prop)
                    desc = _resolve(spec, prop).get("description") or ""
                    fields[name] = (py, Field(..., description=desc)) if name in required else (Optional[py], Field(None, description=desc))
                    where[name] = "body"
            short = NAMES.get(path) or path.strip("/")

            async def call(_path=path, _method=method.upper(), _where=where, **kwargs):
                url, query, payload = _path, {}, {}
                for name, value in kwargs.items():
                    if value is None:
                        continue
                    if _where.get(name) == "path":
                        url = url.replace("{" + name + "}", str(value))
                    elif _where.get(name) == "query":
                        query[name] = value
                    else:
                        payload[name] = value
                response = await client.request(_method, url, params=query or None,
                                                json=payload if _method == "POST" else None, timeout=30)
                try:
                    return response.json()
                except ValueError:
                    return response.text

            tools.append(StructuredTool.from_function(
                coroutine=call, name=PREFIX + short,
                description=(op.get("description") or op.get("summary") or short).strip(),
                args_schema=create_model(f"{short}_args", **fields),
            ))
    return tools

    # in the same process, and the agent "without policies" would follow the other one's policies.

Run:  PORT=7860 ./cuga-docker.sh python playground/web.py

One visitor at a time: this is a local teaching version. The Hugging Face Space adds per-visitor sessions.

import asyncio
import os
from contextlib import asynccontextmanager
from pathlib import Path

import uvicorn
from fastapi import FastAPI, HTTPException
from fastapi.responses import FileResponse
from pydantic import BaseModel, Field

from agents import answer_approval, ask, make_agent
from oak_tools import bills, reset_data
from scenarios import SCENARIOS, check_rules

state = {"agents": {}, "pending": None, "lock": asyncio.Lock()}


@asynccontextmanager
async def lifespan(app: FastAPI):
    state["agents"] = {"without": await make_agent(False), "with": await make_agent(True)}
    yield
    for agent in state["agents"].values():
        await agent.aclose()


app = FastAPI(lifespan=lifespan)


class Ask(BaseModel):
    message: str = Field(min_length=1, max_length=600)


class Decision(BaseModel):
    approve: bool


def _scenario(message: str) -> dict:
    """Use the scenario's rules when the message is one of the buttons. Free text gets the general rules."""
    for sc in SCENARIOS:
        if sc["message"] == message:
            return sc
    return {"rules": ["approval", "denied_claim"]}


def _side(out: dict, message: str, approvals: int) -> dict:
    out = {**out, "approvals": approvals, "bills": bills()}
    out["broken"] = [] if out["paused"] else check_rules(_scenario(message), out)
    return out


@app.get("/")
def page():
    return FileResponse(Path(__file__).parent / "index.html")


@app.get("/api/scenarios")
def scenarios():
    return [{"id": s["id"], "label": s["label"], "message": s["message"]} for s in SCENARIOS]


@app.post("/api/ask")
async def api_ask(body: Ask):
    if state["lock"].locked():
        raise HTTPException(409, "A message is still running.")
    async with state["lock"]:
        reset_data()
        left = _side(await ask(state["agents"]["without"], body.message), body.message, 0)
        reset_data()
        right_raw = await ask(state["agents"]["with"], body.message)
        right = _side(right_raw, body.message, 1 if right_raw["paused"] else 0)
        state["pending"] = {"thread_id": right["thread_id"], "message": body.message,
                            "tools": right["tools"], "approvals": right["approvals"]} if right["paused"] else None
        return {"without": left, "with": right}


@app.post("/api/approve")
async def api_approve(body: Decision):
    pending = state["pending"]
    if not pending:
        raise HTTPException(409, "Nothing is waiting for approval.")
    async with state["lock"]:
        out = await answer_approval(state["agents"]["with"], pending["thread_id"], body.approve)
        out["tools"] = pending["tools"] + out["tools"]
        approvals = pending["approvals"] + (1 if out["paused"] else 0)
        state["pending"] = {**pending, "tools": out["tools"], "approvals": approvals} if out["paused"] else None
        return {"with": _side(out, pending["message"], approvals)}


if __name__ == "__main__":
    uvicorn.run(app, host="0.0.0.0", port=int(os.environ.get("PORT", 7860)))

async function post(url, body) {

# Never pay a denied claim in collections

## Rule
A claim that was denied and whose bill has status IN_COLLECTIONS must not be paid. The member can appeal the denial. Other bills that are due can be paid.

## Steps
1. Retrieve the billing items for the member. For each bill the member wants to pay, note its status.
2. Pay only bills with status DUE. Never create or confirm a payment intent for a bill with status IN_COLLECTIONS.
3. For a bill in collections, tell the member the claim was denied, that the bill is in collections, the amount, and the common reasons for a denial (a duplicate claim, or a service the plan does not cover). Tell the member they can appeal and ask whether they want help with that.
4. In the final answer, list which claims were paid and which were not paid, with the reason.

# My Policy Playground

Two [CUGA](https://github.com/cuga-project/cuga-agent) agents answer the same message for the fictional
Oak Health Insurance. Same model, same tools; only the right one has policies (approvals, guards,
disclaimers and a playbook). Built by following the Policy Playground tutorial.

Set these in the Space's Settings: secrets `OPENAI_API_KEY` and `OPENAI_BASE_URL`, variable `MODEL_NAME`.
For IBM Bob inference, also add the variable `AGENT_SETTING_CONFIG=settings.bob.toml` and start the key with `Apikey `.
